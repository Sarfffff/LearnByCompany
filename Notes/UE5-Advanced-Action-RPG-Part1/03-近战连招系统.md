# 03 近战连招系统

上一章：[[02-英雄角色与基础框架]]　返回：[[00-课程索引]]　下一章：[[04-英雄战斗与反馈UI]]

> [!info] 本章边界
> C++ 负责武器注册、输入路由、AbilitySpec 授予/撤销和动画层访问；轻重攻击连招主体位于 Gameplay Ability 与 Montage 蓝图资产。未能从二进制资产验证的节点、变量和 Section 名不会臆造。

## 总体链路

```text
Input Action → InputTag → ASC DynamicAbilityTags → Gameplay Ability
Gameplay Ability → Montage → Gameplay Event → 装备/连招阶段
Weapon Data → Anim Layer + Mapping Context + Default Abilities
Equip → GiveAbility并保存Handle
Unequip → ClearAbility并清空Handle
```

## 源码审计提醒

- `BindAbilityInputAction` 实际绑定 `Started/Completed`。
- `GrantHeroWeaponAbilities` 的 `SourceObject` 是 Avatar。
- `CastChecked` 不是静默安全失败。
- 当前最终源码部分函数有历史拼写，如 `RemovedGrantedHeroWeaponAbilities`。
- 连招变量和 Montage Section 名必须打开对应 Ability/Montage 资产核对，不能凭标题杜撰。
