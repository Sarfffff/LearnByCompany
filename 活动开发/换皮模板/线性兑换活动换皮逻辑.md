# 线性兑换换皮活动 — 详细操作手册

## Step 1: 配置表配置

### 1.1 打开 Excel 配置文件

**文件路径**：
```
D:\LetsGoEditor\Editor\letsgo_common\excel\xls\H_活动中心配置.xlsx
```

**操作 Sheet**：根据业务选择对应 sheet，对应导出为以下 txt 之一：
- `ActivityMainConfigForLetsGo_common.txt` — 通用活动
- `ActivityMainConfigForLetsGo_modyunying.txt` — 特色玩法运营
- `ActivityMainConfigForLetsGo_design.txt` — 策划专用

### 1.2 新增活动行

在对应 sheet 末尾新增一行，填写以下字段：

| 字段名 | 填写值 | 说明 |
|--------|--------|------|
| `id` | 30999 | 服务端分配的活动ID（必须唯一） |
| `activityType` | `ATLinearRedeem` | 线性兑换枚举值 |
| `activityName` | `春日兑换` | 活动显示名 |
| `activitySubName` | `春日好礼` | 子标题（可空） |
| **`activityUIDetail`** | **`UI_ActivityTemplate_ExchangeLinearView`** | ★ 核心：指向线性兑换模板视图名 |
| `activityNameType` | `ANTLinearRedeem` | 名称类型枚举 |
| `tagId` | 1 | 标签组ID（决定在活动中心哪个Tab下展示） |
| `activityShopType` | 142 | 关联兑换商城的 mallId |
| `activityTaskGroup` | 570011,570021 | 任务组ID列表（逗号分隔，对应不同Tab的任务分组） |
| `backgroundUrl` | `spring_exchange_bg.astc` | 背景图CDN地址 |
| `timeInfo.beginTime` | 2026-07-20 00:00:00 | 活动开始时间 |
| `timeInfo.endTime` | 2026-08-20 23:59:59 | 活动结束时间 |
| `suspend` | 0 | 是否暂停（0=正常） |
| `platforms` | 1,2,3,4 | 支持平台（1=iOS, 2=Android, 3=PC, 4=H5） |
| `lowVersion` | 1.5.61.25 | 最低客户端版本 |
| `showInCenter` | true | 是否在活动中心居中展示 |
| `slapFace` | false | 是否拍脸弹窗 |

### 1.3 配置 clientParams（多Tab页签名）

在 `clientParams` 字段中填写 Tab 名称列表（JSON数组格式）：
```
clientParams: ["春日任务", "兑换商店"]
```

**说明**：
- 模板代码第 68 行：`local tabNames = self.Data.clientParams or {}`
- 每个元素对应一个 Tab，**第一个**通常是兑换商店Tab（由 `ExchangeTabIndex` 控制，默认=1）
- 后续Tab对应 `activityTaskGroup` 中的任务组

### 1.4 配置 activityParam（追赶机制参数，可选）

如果活动需要"消耗道具追赶到当前进度"功能：
```
activityParam: [5, 1300001]
```
- `activityParam[1]` = 5（追赶倍数）
- `activityParam[2]` = 1300001（消耗的道具ID，需在背包表中存在）

模板代码第 218 行读取：
```lua
local CoinId = self.ActivityInfo.activityParam and self.ActivityInfo.activityParam[2]
```

### 1.5 导表

完成 Excel 编辑后，执行导表：

```bash
# 使用项目导表工具
cd D:\LetsGoEditor\Editor\letsgo_common
python export_table.py --table H_活动中心配置
```

导出后检查 `server/data/ActivityMainConfigForLetsGo_common.txt` 中是否包含新增的 `id: 30999` 行。

*导表后的数据服务器也会读取，然后服务端把这些配置表字段和玩家的动态数据打包在一起，通过协议推送给客户端*

## Step 2: 创建 UMG 蓝图

### 2.1 创建 WidgetBlueprint

在 UE4 编辑器中：

1. **Content Browser** 中右键 → `User Interface` → `Widget Blueprint`
2. **命名**：`UI_ActivityTemplate_ExchangeLinearView`（如果美术想用独立名字，如 `UI_ActivityInstance_SpringExchange`，需在配置表和 `UIWndNameToLuaPath.lua` 中同步修改）
3. **保存路径**：`/Game/Feature/System/Assets/CommercialRes/Activity/Activity_SpringExchange/Blueprints/`

### 2.2 设置蓝图父类

1. 打开蓝图 → 点击 `Class Settings`（类设置）
2. **Parent Class**：选择 `MoeLuaWidget`（或 `UMoeLuaUserWidget`）

### 2.3 设置 View 属性（★ 关键）

1. 在蓝图编辑器中，选中根节点 `UI_ActivityTemplate_ExchangeLinearView`
2. 在 **Details** 面板找到 **View** 属性
3. 填入 Lua 模块路径：
   ```
   Feature.System.Script.System.Activity.Public.Template.View.UI_ActivityTemplate_ExchangeLinearView
   ```

> ⚠️ 运行时 `BaseViewClass.GetLuaViewPathByWndNameOrWidget()` 会先查 `UIWndNameToLuaPath.lua`，查不到就读 UMG 蓝图的 `View` 属性。活动UMG通常走后者。

在 `ActivityModelPath` 表中添加：

**注意事项**：

- Value 路径用 `.` 分隔，对应文件系统的 `/`
- 路径末尾不加 `.lua`

### 3.3 创建子模型文件

**文件**：`Instance/SpringExchange/Model/Activity_Instance_SpringExchange_Model.lua`

```lua
local Activity_Instance_SpringExchange_Model = _MOE.class(
    "Activity_Instance_SpringExchange_Model",
    _MOE.SystemSubModel
)

function Activity_Instance_SpringExchange_Model:OnInit()
    self.m_activityData = nil
    self.m_activityId = 0
end

function Activity_Instance_SpringExchange_Model:OnClear()
    self.m_activityData = nil
end

function Activity_Instance_SpringExchange_Model:GetActivityData()
    return self.m_activityData
end

function Activity_Instance_SpringExchange_Model:SetActivityData(data)
    self.m_activityData = data
end

return Activity_Instance_SpringExchange_Model
```

**关键点**：
- 继承 `_MOE.SystemSubModel`（不是 `_MOE.BaseViewClass`）
- 文件末尾必须有 `return Activity_Instance_SpringExchange_Model`
- 通过 `_MOE.Models.ActivityModel.subModels.Activity_Instance_SpringExchange_Model` 访问

### 3.4 创建实例视图文件

**文件**：`Instance/SpringExchange/SubView/UI_ActivityInstance_SpringExchange.lua`

```lua
-- 引用线性兑换模板
local UI_ActivityTemplate_ExchangeLinearView = require(
    "Feature.System.Script.System.Activity.Public.Template.View.UI_ActivityTemplate_ExchangeLinearView"
)

local UI_ActivityInstance_SpringExchange = _MOE.class(
    "UI_ActivityInstance_SpringExchange",
    UI_ActivityTemplate_ExchangeLinearView
)

function UI_ActivityInstance_SpringExchange:OnOpen(Data)
    -- 如需多Tab页签，设置 IsNeedShowTab = true
    Data.IsNeedShowTab = true

    -- 如需调整兑换商城Tab位置（默认第1个）
    -- Data.ExchangeTabIndex = 1

    -- 调用模板的 Init 方法（注意是 . 不是 :）
    self.super:Init(self, Data)

    -- 初始化事件
    self:OnInitializedEvent()

    -- 初始化数据
    self:InitData()

    -- 注册事件
    self:InitEvent()

    -- 初始化UI
    self:InitUI()
end

function UI_ActivityInstance_SpringExchange:InitData()
    -- 先调用父类 InitData
    self.super:InitData()

    -- 如有自定义数据需求，在此处获取子模型数据
    -- local subModel = _MOE.Models.ActivityModel.subModels.Activity_Instance_SpringExchange_Model
    -- local data = subModel:GetActivityData()
end

function UI_ActivityInstance_SpringExchange:InitEvent()
    -- 调用父类（注册任务更新、商城数据等事件）
    self.super:InitEvent()

    -- 如有自定义事件监听，在此处添加
    -- self.child:AddEventListener(SomeEvent, function() ... end)
end

function UI_ActivityInstance_SpringExchange:InitUI()
    -- 调用父类（自动渲染标题、背景、Tab、奖励列表等）
    self.super:InitUI()

    -- 如有自定义UI渲染，在此处添加
end

function UI_ActivityInstance_SpringExchange:OnClose()
    -- 调用父类 OnClose（自动清理 bp、Data、事件监听器等）
    self.super:OnClose()
end

return UI_ActivityInstance_SpringExchange
```

**关键编码规则**：
1. `self.super:Init(self, Data)` — 注意是 `:`（冒号），传入 `self`
2. `self.super:InitData()` — 先调父类再做自己的逻辑
3. 不能直接 `require` 子模型，必须通过 `_MOE.Models.ActivityModel.subModels.XXX`
4. 事件监听用 `self.child:AddEventListener`（OnClose 时自动清理）
5. ❌ 禁止继承另一个活动实例（只能继承模板）

local ActivityUnifiedDefine = {

然后在视图中读取：

local paramValue = _MOE.Models.ActivityModel:GetActivityUnifiedParamByKey(

## Step 6: 协议绑定（通常不需要）

### 判断是否需要

| 情况 | 是否需要 |
|------|---------|
| 活动数据通过 `GetActivityInfo` 获取 | ❌ 不需要 |
| 活动有独立的网络通知 | ✅ 需要 |
| 活动需要监听通用协议（如任务更新） | ❌ 模板父类已处理 |

### 6.1 在子模型中绑定协议

```lua
function Activity_Instance_SpringExchange_Model:BindAllNotify()
    _MOE.NetworkManager:BindNotify(
        _MOE.MsgName2Id.SpringExchangeNtf,
        function(Msg) self:HandleSpringExchangeNtf(Msg) end
    )
end

function Activity_Instance_SpringExchange_Model:HandleSpringExchangeNtf(Msg)
    if Msg then
        self:SetActivityData(Msg)
        -- 通知视图更新
        _MOE.EventManager:DispatchEvent(
            _MOE.Models.ActivityModel.OnActivityInfoUpdateNtf,
            Msg.activity_id
        )
    end
end
```
